# 盲样感官评审工作台

本项目为食品研发实验室提供一次完整的盲样感官评审流程：主持人批量配置有序量表和登记样品，冻结可复现盲码并启动采集；评审员在身份隔离的任务中提交评分或完成重评；主持人关闭采集后由质量复核员原子裁定核验发现，完成双角色解盲批准，查看含并列优选、样本数和极值的结论，最后生成并校验不可变归档凭据。

## 构建、运行与测试

```text
go test ./...
go build ./cmd/server
go run ./cmd/server -addr=127.0.0.1:19081
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

服务默认监听 `127.0.0.1:19081`，也可以使用 `-addr=127.0.0.1:<port>` 或 `PORT` 环境变量配置端口。浏览器访问 `/`，JSON 接口位于 `/api`，数据默认保存在 `./data`。

工作台和 JSON API 均支持批量样品登记、完整量表替换、核验发现批量裁定及重评历史查询。归档包导出前会通过 `/api/archives/{id}/validate` 检查事件链、快照投影、版本、计划和结论摘要；校验失败时不会导出封存包，也不会改变会话或归档状态。
